# Customer Behavior Analysis

## Overview

This project analyzes customer purchasing behavior using **Python, SQL, and Power BI**. The dataset contains over **3,900 customer records**. The project focuses on data cleaning, exploratory data analysis (EDA), customer segmentation, and dashboard creation to generate business insights.

## Tools Used

- Python (Pandas)
- MySQL
- Power BI

## Project Steps

- Cleaned and preprocessed the dataset using Python.
- Handled missing values and renamed columns.
- Created new features such as **Age Group** and **Purchase Frequency**.
- Performed Exploratory Data Analysis (EDA).
- Wrote SQL queries using CTEs, CASE statements, subqueries, and aggregate functions.
- Segmented customers into **New**, **Returning**, and **Loyal** groups.
- Built an interactive Power BI dashboard to visualize customer behavior.

## Key Insights

- Identified loyal and high-value customers.
- Analyzed customer purchasing trends.
- Compared purchase behavior across age groups.
- Studied the impact of discounts and subscriptions.
- Visualized sales trends using Power BI.
